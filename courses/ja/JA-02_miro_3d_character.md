# Modeling Techniques to Bring Out a Character's Charm in 3D (Miro) — JA-02
- Language: Japanese, polite, technical.
- Instructor: Miro (ミロ). TTS: "MEE-roh".
- Discipline: stylized/anime 3D character modeling — likely head/face modeling, body, hair,
  making a character "look cute/appealing" from all angles (どの角度から見ても可愛い), toon shading.
- Software (verify): Blender and/or ZBrush most likely; possibly Maya, Substance Painter, Marvelous Designer.
  Confirm from first screen capture and lock terminology to that application's English UI.
- Core concepts: 可愛さ/魅力 (charm/appeal), 顔のバランス (facial balance), 目の造形 (eye shape/modeling),
  髪の房 (hair tufts/strands), 房分け (grouping strands), トポロジー/エッジフロー (topology / edge flow),
  表情 (expressions, shape keys), アウトライン/輪郭線 (toon outline), 法線編集/法線転写 (normal editing /
  normal transfer — common in anime 3D for face shading), 影の落ち方 (how shadows fall),
  セルルック (cel-look), 三面図に合わせる (matching the turnaround sheet).
- Software vocabulary: see 3D block in _LANGUAGE_NOTES.md. Blender-specific: 編集モード Edit Mode,
  オブジェクトモード Object Mode, スカルプトモード Sculpt Mode, モディファイア Modifier, シュリンクラップ
  Shrinkwrap, ソリッド化 Solidify, データ転送 Data Transfer, 自動スムーズ Auto Smooth,
  マテリアルプレビュー Material Preview, アーマチュア Armature, 頂点グループ vertex group.
- Traps: 面 (face/polygon) vs 顔 (character's face) — both can be "face" in English; disambiguate
  ("polygon face" vs "the face"). エッジ vs 縁; 法線 (normal) is easily garbled by ASR; リグ/リング;
  ウェイト (weight painting) vs 重い (heavy). 割る (to split/add edge loops) vs 割る (to divide numbers).
- Voice: precise; keep step-by-step imperative clarity.
- Verify: software, whether shading/rendering is covered.
