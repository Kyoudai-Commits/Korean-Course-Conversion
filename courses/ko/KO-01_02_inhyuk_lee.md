# The Ultimate Guide to Illustration from Beginner (KO-01) / Advancing to Intermediate Illustration (KO-02) — Inhyuk Lee
- Language: Korean, polite, conversational. Class101 format.
- Instructor: Inhyuk Lee (이인혁). TTS: "IN-hyuk LEE". Known for semi-realistic character
  illustration and Marvel/DC variant covers. Refer to as "Inhyuk" only if he does so himself.
- Discipline: semi-realistic character illustration in Photoshop — from sketch through rendering.
  KO-01 covers fundamentals (line, form, value, basic color, face/figure); KO-02 covers full
  illustration process, lighting, materials, finishing.
- Software: Photoshop (verify tablet/brush setup lesson).
- Core concepts: 덩어리 (mass), 면 (planes), 명암 단계 (value steps), 빛의 방향 (light direction),
  반사광, 고유색, 피부 톤 (skin tone), 머리카락 결 (hair flow), 눈/코/입 (facial features),
  얼굴 각도 (head angles), 러프 → 선화 → 밑색 → 명암 → 채색 → 보정 pipeline, 보정 (post-processing /
  color correction — very common final step: 커브, 색상 균형, 선택 색상), 텍스처 브러시, 커스텀 브러시,
  질감 표현 (metal 금속, leather 가죽, cloth 천, skin 피부), 배경 (background), 빛 효과 (light effects),
  글로우, 컬러 닷지, 오버레이 색 올리기.
- Traps: 보정 = color correction / adjustments, not "correction" in the moral sense; 면 = plane;
  선 따기 = line cleanup; 따다 = eyedropper; 색을 올리다 = layer color on top; "느낌" = feel — often "look".
- Voice: calm, thoughtful, sometimes self-deprecating. Preserve his "in my case…" (저 같은 경우에는)
  framing as "personally, I…".
- Verify: exact chapter list per course to avoid cross-course terminology confusion.
