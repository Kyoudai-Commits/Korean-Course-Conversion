# Character Design for Beginner to Advanced (Tahra) — KO-04
- Language: Korean, polite. Coloso.
- Instructor: Tahra (타라). TTS: "TAH-rah".
- Discipline: character design pipeline — concept/keywords → silhouette thumbnails → costume →
  color → sheet. Likely game/anime-adjacent style.
- Software (verify): Photoshop or Clip Studio Paint.
- Core concepts: 키워드 (keywords), 컨셉, 설정 (backstory/spec), 실루엣 썸네일, 형태 언어 (shape language:
  동그라미/세모/네모 circle/triangle/square), 대비 (contrast in size/shape), 포인트 (accent), 배색 (color
  scheme: 메인/서브/포인트 컬러), 의상 디자인, 소품, 캐릭터 시트 (turnaround), 표정 시트, 정면/측면/후면
  (front/side/back), 직업/성격 (role/personality), 세계관 (world/setting), 통일감 (cohesion), 밀도 조절
  (controlling detail density), 가독성 (readability), 상징 / 모티브 (motif).
- Traps: 설정 ≠ settings; 시트 = sheet; 포인트 = accent/focal point; 캐주얼 = stylized/casual style.
- Verify: software, target genre.
