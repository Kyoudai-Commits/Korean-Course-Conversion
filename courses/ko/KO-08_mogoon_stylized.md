# Fundamentals of Stylized Character Art (Mogoon) — KO-08
- Language: Korean, polite. Coloso.
- Instructor: Mogoon (모군). TTS: "MOH-goon".
- Discipline: stylized (캐주얼 / 데포르메 / 애니메이션풍) character art fundamentals — simplification,
  shape design, clean lines, flat-ish coloring with intentional shading.
- Software (verify): Clip Studio Paint or Photoshop.
- Core concepts: 캐주얼 (stylized — Korean industry term for non-realistic/casual game style),
  단순화 (simplification), 생략 (omission), 강조 (emphasis), 도형화, 선 굵기 / 강약 (line weight
  variation), 깔끔한 선 (clean lines), 셀 채색 / 애니 채색 (cel shading), 1단 명암 / 2단 명암 (one-step /
  two-step shading), 밑색, 그림자 색 (shadow color), 하이라이트, 눈 (eyes — 눈동자 iris/pupil, 흰자 white,
  속눈썹 lashes, 쌍꺼풀 eyelid crease), 머리카락 덩어리 (hair clumps), 실루엣, 비율 (head-to-body ratio 등신:
  2등신 = 2 heads tall, 6등신 = 6 heads), 표정, 매력, 귀엽다 (cute), 가독성.
- Traps: 캐주얼 ≠ "casual clothing" — usually "stylized"; 등신 = head-count proportion; 셀 = cel;
  선 강약 = line weight.
- Verify: software, target style (game vs webtoon vs anime).
