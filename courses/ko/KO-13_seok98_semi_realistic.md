# Transforming Imagination into Semi-Realistic Illustrations (SEOK98) — KO-13
- Language: Korean, polite. Coloso.
- Instructor: SEOK98 (석98). TTS: "SUK ninety-eight" (석 rhymes with "look"). Write "SEOK98".
- Discipline: semi-realistic illustration from concept/imagination — idea → composition → figure →
  rendering → mood/lighting → finishing.
- Software (verify): Photoshop or CSP.
- Core concepts: 상상 (imagination — from title), 컨셉 잡기, 무드 mood, 분위기 atmosphere, 조명 lighting,
  색감 color palette / color feel, 반실사 semi-realistic, 얼굴 얼굴형, 이목구비, 인체, 의상, 배경 요소
  background elements, 공간감, 심도 depth of field / 포커스, 색수차 chromatic aberration, 글로우, 노이즈,
  필터, 보정, 명도 대비 value contrast, 시선 유도, 스토리 story, 감정 emotion, 연출 (staging / direction —
  common Korean word with no single English equivalent: "how you stage the scene").
- Traps: 연출 = staging/direction/presentation; 색감 = palette/color feel; 심도 = depth of field;
  상상 vs 상장; 무드 vs 무대 (stage).
- Verify: software, use of photo bashing / 3D.
