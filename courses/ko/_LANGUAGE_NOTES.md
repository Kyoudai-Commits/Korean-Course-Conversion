# Korean — Language Notes for Localization Agents

## Register and speaker habits
- Coloso/Class101 instructors use polite 해요체/합쇼체. Render as warm, direct instructor English.
- Fillers: 자 (okay / now / so) · 이제 (now — often filler) · 약간 (a bit / kind of — very frequent,
  usually drop or "kind of") · 좀 (a bit) · 뭐 (well / like) · 그냥 (just) · 이렇게 (like this — usually points
  at screen) · 되게 / 진짜 / 엄청 (really) · 일단 (first / for now) · 그래서 (so) · 근데 (but).
- "~해 볼게요 / ~해 보겠습니다" = "let's / I'll go ahead and…". "~해 주세요" = "please X" or "X" imperative.
- "~하시면 돼요" = "you can just…". "~하는 게 좋아요" = "it's better to…".
- Omitted subjects are constant; infer from the demo.
- 여러분 = "you / everyone".

## Homophone / ASR traps
- 선 (line) vs 선 (prior/standing) vs 손 (hand) in noisy audio.
- 면 (plane/side) vs 면 (noodles) — always "plane" in drawing.
- 명암 (values) vs 명함 (business card) — ASR joke but real.
- 빛 (light) vs 빚 (debt) vs 빗 (comb) — hair lessons!
- 눈 (eye) vs 눈 (snow).
- 결 (flow) vs 겹 (layer) vs 결과 (result) truncation.
- 톤 vs 통; 톤을 죽이다.
- 형태 vs 형제; 입체 vs 이빨; 채도 vs 재도 / 자도; 명도 vs 면도 (shaving!).
- 러프 vs 로프 vs 라프; 라인 vs 나인; 레이어 vs 네이어; 브러시 vs 부러지.
- 반사광 vs 반사관; 소실점 vs 소시점.
- 크로키 vs 크로케; 데생 vs 대생 / 데셍.
- Sino-Korean vs native numbers: 한 개 / 두 개 / 하나 둘 vs 일 이 — ASR mixes; also 100% = 백 퍼 / 백프로.
