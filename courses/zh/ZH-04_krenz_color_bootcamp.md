# Zero-to-Hero Color Bootcamp (Krenz) — ZH-04
- Language: Taiwanese Mandarin, traditional. Note Taiwan uses 彩度 for saturation.
- Instructor: Krenz.
- Discipline: color theory applied to illustration — hue/value/saturation, light logic, local vs
  perceived color, warm/cool, palettes, color as composition, common beginner color mistakes.
- Software: Photoshop (verify).
- Vocabulary: 色相 / 明度 / 彩度 hue / value / saturation · 色環 color wheel · 互補色 complementary ·
  鄰近色 analogous · 冷暖 warm/cool · 冷暖對比 · 固有色 local color · 光源色 light color · 環境色 ambient ·
  受光面 / 背光面 lit side / shadow side · 亮部 / 暗部 · 明暗交界線 terminator · 反光 reflected light ·
  投影 cast shadow · 灰 grays / desaturated · 髒 muddy · 粉 chalky (too much white) · 焦 burnt / over-dark ·
  純色 pure color · 灰階檢查 check in grayscale · 黑白灰 value structure · 色調 / 調性 tone / overall tint ·
  統一色調 unify the palette · 配色 palette / color scheme · 主色 / 副色 / 點綴色 main / secondary / accent ·
  色塊 color blocks · 鋪色 block in · 疊色 layer color · 色彩增值 (Multiply) · 覆蓋 (Overlay) · 濾色 (Screen) ·
  加亮顏色 (Color Dodge) · 色彩平衡 · 曲線 · 漸層對應 Gradient Map · 選取顏色 Selective Color ·
  皮膚色 skin tones · 光的顏色 vs 物體的顏色 · 陽光 / 陰天 / 室內光 / 夜景 sunlight / overcast / indoor / night ·
  氣氛 mood · 對比 contrast · 飽和度太高 oversaturated.
- Traps: 彩度 vs 才度 / 採度; 灰 vs 回; 髒 (muddy) vs 髒 (dirty — same word, translate "muddy"); 粉 = chalky,
  not "pink" unless 粉紅; 焦 vs 交 vs 教; 色調 vs 色彩; 亮 vs 量.
